## Standalone prototype demos

Open `index.html?demo=1` in a 1280 × 720 browser viewport. Demo mode hides the **Skills Navigator** header and its prototype-only controls. It keeps the question screens intact, then compacts and centers generated results so all three cards and **Personalize these results** fit in one frame.

Each example has a standalone opening and closing. You can publish either example independently or play them sequentially in about 30 seconds.

## Demo 1: Get a foundational playlist

**Target duration:** 14 seconds.

**Narration:**

> Choose foundational knowledge. One prompt captures the topic, goal, available time, and learning style. Get started now returns a Module, Video, and Lab, with further personalization available.

The narration is 27 words and runs for approximately 11–13 seconds.

### Actions and timing

| Time | On-screen action | Timing note |
|---|---|---|
| 0:00–0:03 | Select **Build foundational knowledge**. | Allow 0.5 seconds for the full preloaded prompt to appear. |

## Recording guidance

- Set the output to 1280 × 720 before you open the page.
- Use `index.html?demo=1`. Don't combine browser device emulation with browser zoom.
- Use the 1600 × 900 reference captures as the source images. They are native, high-resolution 16:9 screenshots and scale cleanly to a 1280 × 720 timeline.
- Don't resize the screenshot files before you add them to the video editor.
- The playlist frames use native CSS sizing. No transform or raster resize is applied.
- Demo mode removes the **Skills Navigator** header, including **Version B** and **Restart**, because that chrome isn't part of the intended final recording.
- Expect each interface transition to take about 0.3–0.35 seconds.
- Budget 0.5 seconds after a selection before you move the pointer.
- Keep the pointer near the next control to reduce dead time.
- Hold each final result long enough for viewers to scan the three cards.
- Don't open **Personalize these results** in these short demos. Point to it to show that deeper refinement is available.
- Start from a refreshed demo URL when you record either example as a standalone clip.
- Use the standard `index.html` URL for normal testing and design review.
